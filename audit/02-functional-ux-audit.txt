================================================================================
NUGX FUNCTIONAL + UX AUDIT
================================================================================

Project   : NUGX gold-trading dashboard
Stack     : Next.js 15 (App Router) / React 19 / TypeScript / Tailwind 4
Audited   : Top-tier testing agent
Method    : Static code review of every component + hook + route, with live
            curl probes against the running dev server (localhost:3001)

Total findings: 96 (+ 15 positive observations)
  BLOCKING   3
  MAJOR      27
  MINOR      45
  NIT        21

================================================================================
0. EXECUTIVE SUMMARY
================================================================================

The codebase is well-commented and has an unusually consistent design system —
nearly every panel reuses the same dark #111/#222/#0a0a0a chrome,
#4ade80/#f87171/#fbbf24 semantic colors, 8-9-10-11px typography ladder. Most
UX issues are visible polish, not structural rewrites.

The structural problems are concentrated in two areas:

  1. PRICE UPSTREAM IS BROKEN (F-01). The gold-api.com mapping doesn't match
     the actual upstream response shape — change/high/low/open/prevClose are
     SILENTLY ZERO on every successful fetch. This poisons the page title,
     PriceBar, BottomBar, the AnalysisRequest sent to Claude, and the chart's
     swingHigh/swingLow inputs. Single highest-impact fix in the codebase.

  2. I18N IS HALF-FINISHED. French and English copy are interleaved across
     PriceBar (UNAVAILABLE / DIRECT), NewsFeed (BULLISH FLOW / MIXED),
     CalendarPanel (passed / in 23m), GoldChart (ALIGNED / UPDATING), the
     entire MEMORY tab, the entire Briefing modal, every alert banner. The
     dashboard switches mid-paragraph.

The accessibility story is the weakest dimension. Tooltips don't focus,
modals don't manage focus, color is the only signaling vocabulary, no live
regions for price or alerts. That's the biggest gap between "looks polished"
and "is professional."

Both structural issues are fixable in a focused day of work.

------------------------------------------------------------------------------
F-01 [BLOCKING] Price API only returns spot — H/L/CHANGE/OPEN are
     permanently zero
------------------------------------------------------------------------------
  LOCATION       app/api/price/route.ts:47-56
  WHAT'S WRONG   The route maps raw.ch / raw.chp / raw.high / raw.low /
                 raw.open / raw.prev_close / raw.timestamp. The actual
                 gold-api.com response (verified live with curl
                 https://api.gold-api.com/price/XAU) only emits: currency,
                 price, name, symbol, updatedAt, updatedAtReadable.
                 So change, changePct, high, low, open, prevClose, timestamp
                 are ALL 0 on every successful fetch. Confirmed:
                   curl localhost:3001/api/price
                   {"price":4615.4,"change":0,"changePct":0,"high":0,
                    "low":0,"open":0,"prevClose":0,"timestamp":0}
  IMPACT         Half of PriceBar (CHG, H, L), the entire BottomBar (OPEN,
                 PREV, CHG, H, L), the page-title arrow/percent, the
                 dayHigh/dayLow tooltips, AND the AnalysisRequest fields
                 high/low/open/prevClose sent to Claude — all silently
                 $0.00 / +0.00%. The model is being told "price is $4615
                 but session high is $0" — that's not just visual breakage,
                 it CORRUPTS EVERY ANALYSIS DECISION.
  FIX            Two options:
                 (a) Drop gold-api.com for OHLC and derive H/L/open/
                     prevClose from the technicals 1H candle history
                     (/api/technicals already returns 1H candles). Compute
                     today's H/L from candles where time >= startOfDayUTC,
                     prevClose from the last candle of the previous UTC day,
                     change/changePct from price - prevClose.
                 (b) Swap upstream to a feed that returns OHLC (metals.dev,
                     Yahoo GC=F).

     cells, ⬆⬇ on flash, dot+letter on signal grid. Touches every
